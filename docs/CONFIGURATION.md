# 설정

## 다운로드 폴더

**저장 설정 → 다운로드 폴더 → 폴더 변경**에서 파일을 저장할 위치를 선택합니다. **폴더 열기**로 Finder 또는 파일 탐색기에서 해당 위치를 엽니다.

선택한 경로는 새로 등록하는 항목에 적용됩니다. 기존 항목은 등록 당시의 경로를 유지합니다. 저장 파일은 항목별 폴더에 배치되며, 앱은 파일의 위치와 출처를 데이터베이스에 기록합니다.

| 환경 | 기본 미디어 위치 |
| --- | --- |
| macOS | `~/Movies/Reelbox Library/Reelbox` |
| Windows | 사용자 Videos 폴더의 `Reelbox Library\Reelbox` |
| Docker | `DOWNLOAD_HOST_DIR` 아래의 `Reelbox` |

외장 디스크를 선택했다면 다운로드 전에 디스크를 연결합니다. 파일을 직접 이동하면 앱의 기록과 실제 위치가 달라집니다. 사본이 필요할 때는 **다른 위치에 저장**을 사용합니다.

## 자동 삭제

기본값은 **자동 삭제 안 함**입니다. 기간을 선택하면 새 항목의 다운로드 완료 시점부터 해당 기간을 계산합니다. 기간이 지나면 파일을 삭제하고 작업 기록은 남깁니다.

**자동 삭제 안 함**으로 변경하고 설정을 저장하면 기존 항목의 삭제 예약도 해제됩니다. 다시 기간을 선택하더라도 이미 보존된 항목에 소급해서 삭제 기한을 부여하지 않습니다.

## 파일명

기본 규칙은 `{date}_{platform}_{title}_{id}`입니다.

| 변수 | 값 |
| --- | --- |
| `{date}` | 저장 날짜, UTC 기준 `YYYYMMDD` |
| `{platform}` | 플랫폼 이름 |
| `{title}` | 미디어 제목 |
| `{id}` | 게시물 또는 미디어 ID |
| `{uploader}` | 작성자 이름 |

파일 이름에 쓸 수 없는 문자는 밑줄로 바꿉니다. 항목별 폴더와 내부 고유 ID를 사용해 이름 충돌을 방지합니다.

## 실행 환경

Docker 설정은 저장소 루트의 `.env`에서 변경합니다. 변경 후 `docker compose up -d`를 실행해 컨테이너를 갱신합니다.

| 변수 | 기본값 | 용도 |
| --- | --- | --- |
| `API_TOKEN` | 설정 스크립트에서 생성 | 웹 서버와 API 간 요청 인증. 최소 24자 |
| `WEB_PORT` | `3000` | 로컬 웹 포트 |
| `DOWNLOAD_HOST_DIR` | `./downloads` | 호스트의 미디어 저장 폴더 |
| `MAX_FILE_BYTES` | `4294967296` | 파일당 최대 4GiB |
| `MIN_FREE_BYTES` | `1073741824` | 저장 전 최소 여유 공간 1GiB |
| `MAX_JOBS` | `50000` | 작업 기록 한도. 설정 범위 2,000–100,000 |

데스크톱 앱은 실행할 때 내부 인증 값을 생성합니다. `.env` 설정은 데스크톱 앱에 적용되지 않습니다.

데스크톱 실행 환경에서 `REELBOX_WORKERS`는 동시 작업 수를 지정합니다. 기본 3개이며 1–6개로 제한합니다. `REELBOX_USER_DATA_DIR`은 앱 데이터 폴더, `REELBOX_DOWNLOAD_DIR`은 기본 다운로드 상위 폴더를 지정합니다. 별도 데이터 폴더를 지정하면 기존 라이브러리와 분리된 앱 상태로 실행됩니다.

## 백업

앱을 종료한 뒤 **앱 데이터 폴더와 모든 미디어 저장 폴더를 함께** 백업합니다.

| 환경 | 앱 데이터 폴더 |
| --- | --- |
| macOS | `~/Library/Application Support/reelbox-desktop` |
| Windows | `%APPDATA%\reelbox-desktop` |
| Docker | `library-data` 볼륨 |

데스크톱 작업 데이터는 앱 데이터 폴더의 `data/reelbox.sqlite3`에 저장됩니다. 폴더에는 로그인 세션과 로그도 포함될 수 있으므로 개인 백업으로 관리합니다. 복원할 때는 앱을 종료하고 미디어의 원래 경로도 유지합니다.
