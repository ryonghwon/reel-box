# 검증 기록

공개 소스 준비일: 2026-11-13. 기준 버전: 1.5.0.

## 이번 공개본에서 실행한 검사

- 백엔드 pytest: **73개 통과**, Redis 전용 2개 생략.
- 데스크톱 Node 테스트: **10개 통과**.
- 라이브러리 Node 테스트: **6개 통과**.
- 프런트엔드 TypeScript 검사 통과.
- Python 정적 검사·서식 검사 및 프런트엔드 서식 검사 통과.
- 데스크톱 런타임 준비 스크립트 구문 검사 통과.

회귀 검사는 임시 DB·임시 다운로드 폴더와 가상 게시물 데이터로 실행합니다. 일반 테스트는 사용자 계정이나 실제 다운로드 기록을 사용하지 않습니다. 영상 변환 검사는 로컬 FFmpeg/FFprobe를 사용합니다.

## 검사 범위

사진 묶음, 혼합 게시물, URL 중복 제거, 제한된 외부 URL, 큰 저장 목록, 대기열 재시작, 자동 삭제 정책, 저장 위치 변경, 기존 파일 보존, 로그인 작업 중단·재개, 원본 게시물과 파일의 연결을 검사합니다.

## 기존 실사용 확인과 한계

macOS Apple Silicon에서 앱 실행, Instagram의 접근 가능한 미디어 저장과 공식 화면 로그인, YouTube 공개 영상 저장·재생을 확인한 이력이 있습니다. 이 문서는 현재 모든 플랫폼에서 다운로드가 가능하다는 보증이 아닙니다. 공개 과정에서 실제 사용자 URL, 계정, 다운로드 개수, 테스트 원본 응답과 로그는 제외했습니다.

Windows x64 설치 파일은 이전에 생성·무결성 검사했으나 실제 Windows 기기에서 설치·실행은 미검증입니다. 이번 공개 준비에서는 데스크톱 바이너리를 다시 빌드하거나 배포하지 않았습니다. TikTok, Threads, Facebook, X의 모든 미디어 유형에 대한 실다운로드 성공을 검증한 것은 아닙니다. 로그인·연령·지역·요청 제한은 각 사이트의 정상 접근 조건에 따릅니다.
