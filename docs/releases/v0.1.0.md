# Reel Box 0.1.0

The first public release of Reel Box, a local library for downloading and organizing video, images, and audio on macOS and Windows.

## Downloads

| Package | System |
| --- | --- |
| `Reel-Box-0.1.0-macOS-arm64.zip` | Apple Silicon Mac |
| `Reel-Box-0.1.0-Windows-x64-Setup.exe` | Windows x64 installer |

The desktop app starts its service and queue automatically. Docker, a separate browser, Python, Node.js, and an AI API key are not required.

## Features

- Batch URL registration, duplicate detection, previews, and download status.
- Video, image, carousel, and audio handling across supported platforms.
- MP4 by default, available-resolution selection, and audio extraction.
- Instagram saved-post imports from ZIP, JSON, or HTML exports.
- A dedicated Instagram sign-in window for posts accessible to your account.
- Image grouping, source links, compact views, search, and platform filters.
- Individual files, ZIP exports, CSV manifests, retries, and screen recording.
- Configurable download folder, filenames, and retention; files are kept by default.

The app retains its Korean interface. Repository documentation and illustrated guides use English. Platform responses and access requirements determine whether an individual item can be retrieved. The app does not bypass DRM or access restrictions.

## Installation

Extract the Mac archive and move **Reel Box.app** to Applications. On Windows, run the installer. Existing library records and downloaded files remain in their original locations when replacing the app.

Mac archives are ad-hoc signed and checked for integrity, but are not notarized by Apple. Windows packages are unsigned. The operating system may require approval before first launch. `SHA256SUMS.txt` contains checksums for both downloads. See [troubleshooting](https://github.com/ryonghwon/reel-box/blob/main/docs/TROUBLESHOOTING.md#mac-blocks-the-application) for Mac first-launch guidance.

See the [user guide](https://github.com/ryonghwon/reel-box/blob/main/docs/USAGE.md) for imports, sign-in, exports, and recording, and [storage settings](https://github.com/ryonghwon/reel-box/blob/main/docs/CONFIGURATION.md) for folder changes and backups.
